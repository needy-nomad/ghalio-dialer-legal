Ghalio Dialer — Setup & Quick Start Guide

Applies to Ghalio Dialer v0.3.2 (com.ghalio.dialer) · Android 13–17

Why Wireless debugging setup is needed once:
Android prevents normal apps from injecting audio directly into a cellular phone call. Ghalio Dialer pairs once with your phone's built-in Wireless debugging (on-device 127.0.0.1 only — nothing leaves your phone, no extra app like Shizuku is needed) so its local voice service can process call audio cleanly.

Step 1 — Install from Google Play Internal Testing

  1. Make sure your Gmail address is added to the test list.
  2. Open the tester opt-in link on your Android phone:
    https://play.google.com/apps/internaltest/4698960626144825156
  3. Tap Accept invite → Download it on Google Play → Install.
    (If you previously sideloaded an APK build of Ghalio Dialer, uninstall that sideloaded build first so Google Play's signed version can install.)

Step 2 — Default Phone App & Basic Permissions

  1. Open Ghalio Dialer and tap Voice filter setup (from the prompt or 3 dots → Settings → Setup and phone check).
  2. Complete Step 1: Default phone app → select Ghalio Dialer.
  3. Grant Contacts (to distinguish unknown callers from saved contacts), Microphone (for Live Voice Filter & voice previews), and Notifications (used to enter the pairing code).

Step 3 — One-Time Wireless Debugging Pairing

Enable Developer options (if not already enabled):
  1. Open Android Settings → About phone (on Xiaomi HyperOS: tap OS version 7 times; on stock/other phones: tap Build number 7 times).
  2. Connect your phone to Wi-Fi.
  3. Go to Settings → Additional settings / System → Developer options and turn ON Wireless debugging.
    Realme / ColorOS / OnePlus note: also turn ON Disable permission monitoring in Developer options.
  1. Open Ghalio Dialer → Voice filter setup → Step 4: Voice service and tap Pair. A pairing notification will appear.
  2. Open Android Developer options → Wireless debugging and tap Pair device with pairing code (keep that 6-digit code window visible).
  3. Swipe down the notification shade, tap Enter code on the Ghalio Dialer notification, type the 6-digit code, and send.
  4. Return to Ghalio Dialer Setup → wait a few seconds for the voice service to connect → tap Run check (verifies your phone's call-audio support) → tap Turn on voice filter.

Step 4 — Using 1-Tap Controls During Calls

  • Incoming Call Screen (Before Answering): Tap one of the 3 pills right above the Answer button — Normal, Filter (or current preset like Deep ▾), or Phrases — before swiping/tapping Answer.
  • Filter Button (Live Voice Filter): 1 tap toggles Live Voice Filter ↔ Normal voice. Long-press the Filter button (or tap Voice filter on: Deep ▾) to pick another preset (Deep, Robot, Custom).
    Note: Live Voice Filter requires a phone that supports hardware call-screening mode (e.g., Qualcomm Snapdragon / Xiaomi 17). On devices where the chipset blocks hardware call screening, use Speak for me (Phrases) below.
  • Phrases Button (Speak for me): 1 tap switches to Speak for me and opens the quick-phrase drawer — tap any ready English/Hindi phrase or type custom text to speak cleanly to the caller while your microphone stays muted.
  • 1-Tap Return to Normal Voice: While in Filter or Phrases, tap the active Filter button, active Phrases button, Normal inside the Phrases drawer, or the call Mute button — any of these puts your Normal voice back on the line in 1 tap.

After a Phone Reboot

Android automatically turns Wireless debugging off whenever your phone restarts. You do not need to enter the pairing code again:

  1. Make sure Wi-Fi is connected.
  2. Turn ON Developer options → Wireless debugging.
  3. Open Ghalio Dialer once — the voice service reconnects automatically in a couple of seconds.
